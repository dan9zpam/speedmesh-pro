# speedmesh — Расширение для преподавателей МЭШ

**speedmesh** — расширение для браузеров на базе Chromium (Google Chrome, Яндекс Браузер, Microsoft Edge, Opera), предназначенное для автоматизации рутинных задач, быстрого выставления оценок, ведения кураторской отчетности и навигации по электронному журналу **МЭШ** (школы и СПО / колледжи) на доменах `school.mos.ru` и `dnevnik.mos.ru`.

---

## 🚀 Основные возможности

### 1. Кураторская отчетность и сводные ведомости (МЭШ СПО)
- **Сводная ведомость успеваемости на текущую дату:**
  - Автоматический сбор оценок по всем дисциплинам группы куратора.
  - Очистка от технических полей и дат календарно-тематического плана (КТП) МЭШ.
  - Точный расчет среднего балла по каждой дисциплине и общего среднего балла студента.
  - Автоматическая классификация: *Отличник*, *Хорошист*, *Аттестован*, *Задолженность*.
  - Фильтрация по статусам (все / должники / отличники / хорошисты) и мгновенный поиск по фамилии.
  - Экспорт в `.csv` (полная совместимость с Microsoft Excel, МойОфис и Google Таблицами) с фиксацией даты среза в имени файла.
  - Кнопка **«📋 Список долгов»**: копирование форматированного списка академических задолженностей для отправки в кураторский чат или отчетности администрации.
- **Пакетная выгрузка журналов в ZIP:**
  - Скачивание всех ведомостей дисциплин группы в формате `.xlsx` в один клик.
  - Упаковка в единый структурированный ZIP-архив на стороне клиента без отправки данных на сторонние серверы.
- **Быстрый доступ:** запуск генерации ведомости доступен как из плавающей панели на вкладке журналов группы, так и из всплывающего окна (Popup) расширения на любой странице МЭШ.

### 2. Интерактивный таймер занятия и быстрая навигация
- **Плавающий виджет таймера:**
  - Точный обратный отсчет времени до конца текущей пары или перемены.
  - Цветовая индикация фазы занятия: урок, перемена, последние минуты пары.
  - Темы оформления: *Apple Glass (Светлая / Темная)*, *Liquid Glass (Стеклянные блики)*, *Неоновый космос*, *Матрица*, *Минимализм*.
  - Кастомизация интерфейса: настройка масштаба (zoom), радиуса скругления, прозрачности фона и силы размытия стекла (backdrop-filter).
- **Переход к журналу по двойному клику:**
  - Двойной клик на плавающий таймер определяет текущее занятие по дню недели и времени и сразу открывает электронный журнал нужной группы.

### 3. Работа с журналом и выставление оценок
- **Умный прицел (Crosshair):** перекрестная подсветка активной строки студента и столбца даты урока для исключения случайного выставления оценки не в ту строку.
- **Калькулятор и прогнозирование среднего балла:** расчет необходимых оценок для достижения желаемого итогового балла с учетом веса контрольных точек.
- **Массовые операции:** быстрое выставление оценок за самостоятельные и проверочные работы, управление весами оценок.
- **Рандомайзер студентов:** выбор случайного студента для ответа без предвзятости.

## 📥 Пошаговая инструкция по установке

### Шаг 1. Получение файлов расширения
#### Вариант A. Скачивание архива (простой способ)
1. На странице репозитория нажмите зеленую кнопку **Code** ➔ **Download ZIP**.
2. Распакуйте скачанный ZIP-архив в постоянную папку на компьютере (например, в `Документы` или отдельную папку проектов).
   > **Важно:** не удаляйте и не перемещайте эту папку после установки, иначе браузер потеряет доступ к расширению. Внутри должна быть папка со служебным файлом `manifest.json`.

#### Вариант B. Клонирование через Git (рекомендуется для получения обновлений)
В терминале (macOS/Linux) или командной строке Git Bash (Windows):
```bash
git clone https://github.com/dan9zpam/speedmesh-pro.git
```

---

### Шаг 2. Загрузка в браузер

Подходят любые браузеры на движке Chromium: **Google Chrome**, **Яндекс Браузер**, **Microsoft Edge**, **Opera**, **Brave**.

1. Откройте страницу управления расширениями:
   - В **Google Chrome**: введите в адресной строке `chrome://extensions/` и нажмите `Enter`.
   - В **Яндекс Браузере**: перейдите по адресу `browser://extensions/`.
   - В **Microsoft Edge**: перейдите по адресу `edge://extensions/`.
2. В правом верхнем углу страницы включите переключатель **«Режим разработчика»** (*Developer mode*).
3. В левой верхней части экрана нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. В появившемся окне проводника выберите рабочую папку расширения (где находится файл `manifest.json`) и нажмите **«Выбрать»**.
5. Расширение **speedmesh** появится в списке установленных расширений.

---

### Шаг 3. Первичная настройка и закрепление

1. Нажмите на иконку «пазла» (Расширения) на панели инструментов браузера справа от адресной строки.
2. Найдите **speedmesh** и нажмите значок **булавки / закрепить**, чтобы иконка всегда была под рукой.
3. Перейдите на сайт МЭШ: [school.mos.ru](https://school.mos.ru) (или обновите уже открытую вкладку клавишей `F5` / `Cmd + R`).
4. Авторизуйтесь под своей учетной записью преподавателя. Плавающие инструменты и меню расширения активируются автоматически.

---

## 🔄 Как обновлять расширение

Когда в репозиторий выходят новые обновления и исправления:

1. **Если ставили через Git:**
   Перейдите в папку расширения в терминале и выполните:
   ```bash
   git pull origin main
   ```
2. **Если скачивали архивом:**
   Скачайте свежий ZIP-архив из репозитория и распакуйте с заменой файлов в ту же папку.
3. Откройте `chrome://extensions/` и нажмите иконку **круговой стрелки (Обновить)** на карточке расширения speedmesh.
4. Обновите вкладку журнала в МЭШ (`F5` или `Cmd + R`).

## 🛠 Совместимость и безопасность

- **Поддерживаемые платформы:** МЭШ Школы, МЭШ СПО (Колледжи), dnevnik.mos.ru.
- **Операционные системы:** Windows 10/11, macOS, Linux.
- **Безопасность:**
  - Расширение работает строго локально в контексте браузера пользователя.
  - Используются существующие авторизационные токены текущей активной веб-сессии МЭШ.
  - Никакие персональные данные учащихся, оценки или токены не сохраняются на внешних серверах и не передаются третьим лицам.
