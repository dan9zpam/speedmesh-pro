# SpeedMESH PRO — Расширение для МЭШ (Московская электронная школа)

Бесплатное расширение для браузеров на базе Chromium (Google Chrome, Яндекс Браузер, Edge), созданное для оптимизации и автоматизации работы преподавателей в электронном журнале **МЭШ** (школы и СПО / колледж) на доменах `school.mos.ru` и `dnevnik.mos.ru`.

---

## Возможности

### 1. Выставление и управление оценками
- **Быстрый ввод:** выставление и корректировка оценок в один клик без долгих диалоговых окон.
- **Массовое выставление по столбцам (датам):** заполнение оценок за контрольные, самостоятельные и практические работы сразу всему классу/группе.
- **Контроль веса оценок:** принудительная установка требуемого веса оценки перед сохранением.
- **Быстрая отмена:** удаление ошибочно выставленной оценки по горячей клавише или кнопке отмены без перегрузки страницы.

### 2. Журналы куратора и отчетность (МЭШ СПО)
- **Пакетная выгрузка журналов группы:** автоматическое скачивание всех журналов предметов группы куратора в формате Excel (`.xlsx`) за выбранный учебный год.
- **Единый ZIP-архив:** упаковка всех ведомостей в один структурированный архив в один клик.

### 3. Тематическое планирование и КТП
- **Автоматизация КТП:** быстрое прикрепление и синхронизация календарно-тематических планов.
- **Управление домашними заданиями:** массовое добавление и проверка ДЗ прямо из карточек расписания.

### 4. Посещаемость и аналитика
- **Учет пропусков:** сводный подсчет пропущенных часов и занятий по уважительным и неуважительным причинам.
- **Калькулятор среднего балла:** расчет и прогнозирование итоговой оценки студента с учетом весов контрольных точек.

### 5. Инструменты урока и интерфейс
- **Таймер урока:** плавающий виджет с отсчетом времени до звонка.
- **Случайный выбор (рандомайзер):** выбор отвечающего ученика без предвзятости.
- **Плавающие окна:** перемещение всех модулей по экрану с сохранением позиций.
- **Темы оформления:** светлая, темная и компактная темы интерфейса.

## Установка

1. Скачайте репозиторий: нажмите **Code** ➔ **Download ZIP** и распакуйте архив на диск.
2. Откройте в браузере страницу управления расширениями: `chrome://extensions/` (или `browser://extensions/` для Яндекс Браузера).
3. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите распакованную папку `speedmesh`.
5. Откройте или обновите вкладку журнала МЭШ (`https://school.mos.ru/`).

## Совместимость

- **Поддерживаемые системы:** МЭШ (общее образование), МЭШ СПО (колледжи и техникумы).
- **Сайты:** `school.mos.ru`, `dnevnik.mos.ru`.
- **Браузеры:** Google Chrome, Яндекс Браузер, Microsoft Edge, Opera, Brave и любые Chromium-совместимые браузеры.

---

## Безопасность и конфиденциальность

Расширение работает локально в браузере пользователя, взаимодействует напрямую с официальным API МЭШ с использованием текущей активной сессии преподавателя и не передает учетные данные третьим лицам.
