# SpeedMESH PRO

Современное, мощное и бесплатное расширение для электронного журнала МЭШ (Московская электронная школа). 

## О проекте

SpeedMESH PRO — это инструмент с открытым исходным кодом, созданный для того, чтобы избавить учителей от рутины при работе с электронным журналом. В отличие от существующих платных аналогов, данный проект предоставляется полностью бесплатно и нацелен на максимальное ускорение работы с оценками и планированием.

## Основные возможности

- Умное выставление оценок: выставление и понижение оценок в один клик прямо в интерфейсе журнала.
- Выставление по датам (столбцам): быстрое закрытие контрольных и практических работ у всего класса одновременно.
- Точное управление весом оценки: возможность принудительно задать необходимый вес для оценки (например, вес 2 для практической работы) перед отправкой на сервер.
- Ассистенты урока: встроенный таймер, генератор случайного выбора ученика и калькулятор прогнозируемого среднего балла.
- Кастомизация интерфейса: модульная система окон (виджеты можно свободно перемещать по экрану), переключение тем оформления и "режим невидимки".
- Умная отмена: удаление ошибочных оценок одним кликом или сочетанием клавиш без необходимости открывать стандартный интерфейс МЭШ.
- Встроенная геймификация: система профессиональных достижений для учителей.
- Быстрое управление домашними заданиями: удобный выбор и массовое прикрепление ДЗ прямо из карточек расписания.

## Установка

1. Скачайте код репозитория (кнопка Code -> Download ZIP) и распакуйте архив в удобную папку.
2. Откройте браузер на базе Chromium (Google Chrome, Яндекс.Браузер, Edge) и перейдите на страницу управления расширениями: `chrome://extensions/`.
3. Включите "Режим разработчика" в правом верхнем углу.
4. Нажмите кнопку "Загрузить распакованное расширение" и выберите папку, в которую вы распаковали архив.
5. Обновите страницу с электронным журналом МЭШ.
